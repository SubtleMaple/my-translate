# 现行业务规则

适用的是 [CURRENT_STATE](CURRENT_STATE.md) 标明的当前主线代码基线，推荐规则已随本轮主线整合纳入。历史计划/发布标签中的行为不能自动替代本章。

## 翻译与输入状态

- 英译中流式显示；修改/清空原文使旧请求失效并取消网络，迟到chunk/done/error不能覆盖新文本。
- 完成、停止、失败为不同状态；停止后的部分译文不能显示为正常完成。
- 粘贴并翻译替换全文；Windows右键粘贴替换选区，Android保留系统长按粘贴。异步读剪贴板期间输入若变化，不能再覆盖新输入。
- 极简主要展示翻译，隐藏常规导航/摘词等界面；Windows最小260×140，退出恢复完整窗口约束；关闭Windows窗口是隐藏到托盘。
- 入口：[translateStore](../src/renderer/src/stores/translateStore.ts)、[TranslateView](../src/renderer/src/components/translate/TranslateView.tsx)、[translate.ts](../src/main/llm/translate.ts)。

## 逐位置摘词与词头归一

1. 同一拼写在不同位置是独立目标。单词序号用于UI选择，跨IPC用UTF-16字符范围；仅相同范围去重。
2. Windows拖选短语；Android“选短语”模式点首词、再点尾词。短语和单词可以同时保留，预览、计数、提交使用同一目标集合。
3. 主进程验证目标文本和完整单词边界，给模型每个target独立ID及before/selected/after和全文，逐项核对返回结果。
4. 词头按语境归一，不机械删后缀：动词went可归go，名词meeting、形容词interesting、固定复数clothes按独立词义处理。无语境歧义不强行猜测；语言判断由配置模型完成。
5. 先归一再一次性入库；网络/解析失败保留选择。新词进入pending队列，串行生成详情；429按既有队列策略退避，失败可手动重试，启动恢复pending。
6. 同批归入同一词头只计一次；不同位置来源全部保留。既有词头保留原备注/详情，重复摘录增加count；旧词库不批量改名合并。
7. “✓”仅表示同一原文、准确范围已有来源。无位置旧来源不能推断所有同形词已收录；修改原文/删除词条要刷新标记。
8. 主进程正常摘词限制每批1–50个目标、词/短语最长160字符、原文最长100,000字符，以 [normalizeWord](../src/main/llm/normalizeWord.ts) 校验为准。

来源可保留原始语境；发送模型时命中L1的上下文及focus会被省略，不用删减后的文本覆盖原来源。验证典型句：`I saw a rusty saw lying on the workbench.` 两处应独立提交。

## 查词与收藏

- 普通菜单输入单个英文词查询，支持连字符/撇号、取消和重试；编辑输入/新请求淘汰旧回包。
- 查询成功生成WordLookup，普通查词先归一，推荐入口按候选ID解析已验证词头和目标义项。
- 查询本身不入生词本、不加摘录count，但成功后记录查询历史并消费匹配的推荐候选。
- 点击收藏才入库，复用主进程最近30份结果缓存；重复收藏已有词幂等、不改备注、不加count。缓存过期需重新查词。
- 推荐生成和查词可分别取消，发起查词优先中止后台推荐。实现见 [lookupService](../src/main/services/lookupService.ts)。

## 推荐候选队列

这是当前最重要的需求边界。实现：[recommendationService](../src/main/services/recommendationService.ts)、[recommendationRepo](../src/main/db/recommendationRepo.ts)、[共享状态/排序](../src/shared/recommendations.ts)、[推荐提示词](../src/main/llm/recommendations.ts)。

### 批次与消费

- 请求模型推荐10词，保留本次结果中至多10个有效候选；不足10个也保留有效结果，不自动追加请求凑数。
- `batchIds`保存本批全部候选，`queueIds`保存未消费顺序，`currentIds`显示有效队列前3个；`remainingCount`包含当前展示词。
- 同批消费只移除对应词及匹配变体，其余顺序不变；补位仅使用本批，不能从历史候选库拼接一批。

| 操作/状态 | 本地队列结果 | 是否允许生成 |
|---|---|---|
| 首次无批次，模型与难度条件已满足 | 初始化第一批 | 允许一次初始化；普通入口受60秒尝试间隔控制 |
| 读当前页面、切菜单、重启 | 保留未消费队列与顺序 | 否 |
| 成功查词 | 移除匹配词，前3个由本批补位 | 否 |
| 查词失败/取消 | 不消费 | 否 |
| 收藏、标记已认识/不感兴趣 | 移除匹配词并本地补位；查询后收藏不重复消耗 | 否 |
| 撤销反馈 | 移除该反馈限制，真实查询冷却仍生效；不插回已消费本批 | 否 |
| 还剩2/1/0个 | 展示实际余量，耗尽保持空队列 | 否 |
| 缓存过期、模型/难度/词库变化 | 下次生成使用新条件；不按新画像重新排列未消费队列 | 否；已收录/已消费等无效候选仍会被本地剔除 |
| 用户点刷新 | 成功后原子替换整批，失败/取消保留旧批 | 是 |
| 旧 `action: next` | 兼容读取当前队列 | 否 |

`allowGenerate:false` 的调用仅使用/整理本地队列，不发起模型请求；读取仍可能持久化过滤结果和展示记录。`batchIds:null` 与耗尽的 `[]` 必须区分。新候选与新状态一起提交，不用“返回页时自动生成”掩盖空队列。

表中失败指业务/模型请求失败。平台落盘失败可能发生在SQL已提交之后，不能将所有RPC错误都视为已回滚，见 [事务与保存失败](DATA_MODEL.md#事务与保存失败不是一回事)。

### 导入阅读语料

选取单个 TXT、Markdown、DOCX 或带文字层的 PDF 后自动筛选，原文件和正文只在本机解析。纯文本支持 UTF-8 与带 BOM 的 UTF-16，DOCX 拼接正文段落中的文本片段，PDF 逐页提取文字层，跳过图片。纯扫描件、密码保护、超限或解析失败会显示原因。单文件上限 16 MiB、200 万字符，PDF 至多 1500 页。

扫描整份语料，超过 12000 个不同英文词形时提示拆分。保留代表性大小写，合并规则屈折和常见不规则形式并累计出现次数，跳过明显语气音。随后，使用通用书面语词频排名粗估难度。参考已分析的词库等级；缺少分析时参考代表词的词频分档，冷启动默认 B1。优先同级与相邻等级的词，复现次数提高优先级。曾展示后查阅的词给相应等级正反馈，已收藏者权重更高；多次标记已认识可提高起点，不感兴趣降低同档优先级。全库、当前批次、近期查阅和显式反馈参与排除，常见屈折词形按词族去重。

待推荐语料池最多 1200 词。导入有新增且当前队列为空时立即启用首批；有余量时保留当前顺序。手动刷新优先从池中按最新条件取最多 10 词；本批的消费与展示规则沿用上表。本地模式和从池内组批均离线。点击语料词后走普通查词归一和解释；同一个文件重复导入不叠加词频。

选择 AI 精筛后，共用本地预筛，保留偏高词频难度档的候选供模型校正。每批最多审校 40 个不同候选，顺序覆盖全部预筛结果。模型只见目标等级和候选的 ID、词头、代表拼写及变形；模型排除专名、语气词、明显基础词及透明派生，返回相联的规范词头和估计等级。跨批合并后再按最新词库、队列、反馈、难度与池余量筛选，保留原候选记录。模型估计参与卡片与后续排序。重新导入时已有候选会在送审前排除；曾被拒绝且未入池的词在主动重新导入时可以再次送审。

审校支持 -ic 动词加 k 和 -ie 动词变 y 的屈折拼写，以及常用词频表未覆盖的 re- 构词（须有已知基词并能核对完整词形）。排除项按候选 ID 和原因处理，保留与归并须核对词头及等级。按提交编号逐词判定；漏回、同一编号重复、字段或词形无效只跳过对应词，额外编号忽略。新导入的跳过项不入池，已有候选复筛时原位保留。进度与完成提示显示跳过数量。网络失败、JSON 无法解析或缺少结果列表时保留检查点，等待用户继续。

完成的批次在下一批请求前落盘。反馈、预览、查词、日常刷新各自独立；退出程序或网络错误后由用户继续任务。暂停会取消尚未完成的请求，已发出的请求可能已被服务商计费。中途不把部分结果写入推荐池，放弃任务只移除该任务。旧池不启动自动清理。

预览内可主动发起一次现有候选复筛，未勾选时处理列表全部候选，有勾选时只处理所选词。翻页保留选择，全选覆盖所有页；批量删除通过一次本地写入完成。复筛使用已配置的模型，延续检查点和暂停/继续规则，直到整项成功才原位保留、归并或移除。已消费、已删除或已经换批的目标跳过；未选词保留原位置。

「预览语料词」列出当前批次中尚未消费的语料候选，随后列出语料池的全部储备词（包括暂不符合当前画像的词）。每页 40 词。删除储备词立即移出池；删除本批词立即移出剩余队列，仍按本批原始大小显示进度。删除仅修改推荐状态，生词本、查询历史及难度反馈独立保存。以后主动重新导入仍按通常的去重和冷却规则筛选。

### 难度与候选质量

- 生词本是学习需求，不等于已掌握水平。取近期24、高频18、历史均匀18的代表集合并补齐，最多60词；新增/变化证据才重新分析，每批最多20词。
- 难度为CEFR估计；按近期、有限频次和置信度加权中位数，足够通用样本时专业离群词不拉高整体等级。
- 样本含词头、词性、简释和必要安全语境，不含个人备注或完整Markdown。发模型的排除提示有上限，本地仍按全量词库排除。
- 本地考虑同级/相邻级、领域、实用性、同词族/同义集中；所有打分和等级都是启发式估计。
- 已认识长期排除；不感兴趣90天并影响主题排序；展示冷却7天，查询冷却30天。批内读取忽略自身展示冷却，避免刚显示就消失。
- 难度反馈仅影响下次生成，空词库先选起始等级。推荐规则不调用自测评分来增加摘录count。

## 自测与间隔复习

实现：[reviewService](../src/main/services/reviewService.ts)、[reviewScheduler](../src/main/services/reviewScheduler.ts)、[reviewSelection](../src/shared/reviewSelection.ts)。

- 仅ready且有词头/简释的词可出题；范围可选全库或当前搜索。UI默认10词，可选5/10/20/50，服务接受1–50，不足按实际数量。
- 英文→回忆释义，揭晓后四档自评：1忘了、2费力想起、3记得、4很熟。看到答案才想起应选1。
- 智能抽样约80%到期＋20%未测，池不足互补；到期积压达到本轮数3倍时优先到期。约20%到期名额保底最早到期，其余带权不放回；未测保留最老词，余下温和参考近期/摘录频次。
- 全库随机是额外练习，允许未到期词，按真实评分时间更新FSRS。初始队列不重复且持久化seed/顺序。
- 使用ts-fsrs 5.4.2、目标保持率0.9、学习/重学步骤1m/10m；参数为模型调度目标，不保证实际记忆率。
- Again后最少隔3道其他题且到时（至少一分钟）才加练，同词本轮最多额外2次。没有合适下一题就结束本轮，未来到期安排保留。
- 跳过不评分；退出页面/切菜单不记错；“结束本轮”主动停止剩余题。“退出自测”只是回列表，重启可继续未结束会话。
- 撤销恢复上一题前的记忆状态与队列，旧revision不能重复记分；首次自评、加练、跳过分别统计。
- 删除或释义不可用时跳过对应待测题，不通过撤销复活已删词。评分和撤销事务后通知词库更新学习状态。

## 熟悉度与可视化

实现：[vocabViewService](../src/main/services/vocabViewService.ts)、[learning.ts](../src/shared/learning.ts)、[词云布局](../src/renderer/src/lib/wordCloud.ts)。

- 长期熟悉度用FSRS稳定性S、学习/重学阶段及跨日成功依据；即时遗忘风险为 `1-R`。刚看过答案的“待巩固·风险低”并不冲突。
- 分级：无记忆卡=未自测；最近Again或Relearning=待巩固；Learning或缺跨日依据=学习中；其余Review按S<30天=逐渐稳定，S≥30天=较稳固。跨日须至少两次成功自评相隔24小时，跳过/撤销不计。
- 不熟/熟悉排序先阶段再S；未知单独置后；风险排序按当前概率。无效值不显示伪0分，时钟回拨时当前风险可暂无估计。
- 列表、词云、分组共用搜索与阶段筛选。视图/排序/云指标保存偏好；词云字号是有界视觉权重，非掌握百分比，未知采用中性值。
- 同数据/尺寸布局确定；默认尝试150词、可增到450，余词以补充列表访问，不截断长词或把短语拆成多个词条。
- 点击词云/分组以ID打开独立详情；备注变更导致离开当前筛选时，打开详情仍可编辑。删除后关闭。
- 每次查询统一evaluatedAt，进入词库、退出自测、窗口激活、手动刷新和可见词库学习变更时更新；不持续重排正在阅读的图形。

## 导出、设置与平台边界

- 全量导出当前平台词库，包含pending/failed；与列表筛选、自测范围无关。JSON/CSV的精确字段及公式文本还原见 [README](../README.md#词库导出格式与分析)。
- 导出是词条分析文件，不是设置、推荐队列或完整复习状态的备份；两端快照/保存位置差异见数据手册。
- 普通模式包括翻译、查词、生词本、设置；极简显示翻译。六套配色与light/dark/system独立持久化。
- Android隐藏桌面窗口控制，触屏选短语与长按粘贴使用手机交互；手机与Windows数据独立，无导入/自动同步/跨应用悬浮窗。改变边界需作为明确新需求处理。

## 不可混淆的量

| 名称 | 实际含义 |
|---|---|
| 位置目标数 | 原文中独立选择的范围数量 |
| 归一词头数 | 本批模型判断后用于入库去重的数量 |
| count | 手动摘录次数，不是模型词频、自测次数或推荐点击次数 |
| 来源数 | 不同原词/原句/位置的记录数量 |
| 自测次数 | 有效评分记录/FSRS状态对应次数，首次与加练统计另分 |
| 候选余量 | 当前批次尚未消费数量，包含正在展示的词 |
| 长期熟悉度 / 当前风险 | 长期记忆依据 / 当前时刻回忆概率估计 |
