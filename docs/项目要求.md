你是一位资深桌面应用开发工程师，请从零开发一个运行在 Windows 11 上的本地「英汉翻译 + 生词本」软件。

### 核心定位

这是一个**悬浮窗式**的本地工具。用户可以一边看其他地方的英文原文，一边用这个窗口翻译和收集生词。窗口必须支持：

- 自由拖动
- 自由缩放大小
- 可开启「始终置顶」（Always on Top）
- 关闭时最小化到系统托盘，而不是直接退出程序

### 技术选型（强制，针对 Windows 优化）

- 框架：Electron + Vite + React + TypeScript
- UI：Tailwind CSS + shadcn/ui（必须使用）
- 状态管理：Zustand
- 本地数据库：**sql.js**（纯 WebAssembly SQLite，禁止使用 better-sqlite3 或其他需要编译的原生模块，避免 Windows 上安装 Visual Studio Build Tools 的麻烦）
- 数据持久化：把 sql.js 的数据库文件保存到用户本地目录（使用 electron-store 或直接写文件）
- LLM 调用：支持任意 OpenAI 兼容 API（用户在设置里自行配置 baseURL、apiKey、model）
- 包管理：pnpm
- 打包：使用 electron-builder，最终输出 Windows 安装包（.exe / NSIS）
