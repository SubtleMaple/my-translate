# My Translate — 英汉翻译 + 生词本

Windows 11 本地悬浮窗翻译工具：一边看英文原文，一边翻译、收集生词，词条自动生成音标/释义/例句/近反义词等学习详情。

**公开 Windows 版本：0.3.0** · [下载安装包](https://github.com/SubtleMaple/my-translate/releases/tag/v0.3.0) · [版本更新记录](CHANGELOG.md)

本文功能说明对应当前检出的开发源码；Android与最新推荐队列包含公开Windows版本之后的开发成果，不能仅凭相同版本号判断安装包能力。已发布版本与最新主线的区别见 [当前开发状态](handbook/CURRENT_STATE.md)。

## 功能

- **悬浮翻译窗**：自由拖动 / 缩放 / 始终置顶 / 窗口透明度 / 关闭最小化到系统托盘
- **流式翻译**：支持 OpenAI 兼容 / Anthropic API；粘贴并翻译、复制译文，修改原文自动清除旧译文，停止结果明确标为未完成
- **语境摘词**：每个单词按原文位置独立点选，支持拖选连续短语；同形词分别传入位置及上下文辨义（如同句两个 saw 可分别归为 see 与 saw）。模型判断后按词头入库，同批归入同一词头只计一次，保留每处来源。已有词条不批量整理
- **单词查询**：普通模式「查词」输入单词即生成完整学习解释，支持取消与重试；点击收藏才加入生词本，复用已生成解释，查词与重复收藏不增加出现次数
- **智能推荐**：每批生成10个候选，界面显示最多3个；查词成功后从本批剩余候选补位，用完后仅手动刷新生成新批次；支持「已认识 / 不感兴趣 / 撤销」和「偏简单 / 合适 / 偏难」，排除已收录及近期见过的词，模型推荐查词时携带目标义项，语料推荐走普通查词归一
- **生词本**：搜索（单词/释义/例句/备注）、时间/字母/出现次数及不熟优先/熟悉优先/遗忘风险排序、Markdown 学习详情、个人备注、失败重试
- **多视图词库**：列表 / 词云 / 熟悉度分组切换；按学习状态筛选；词云字号可选不熟程度、摘录次数、熟悉程度，颜色体现长期阶段，点击词语可查看记忆概况与编辑词条
- **随机自测与间隔复习**：逐题回忆英文释义，揭晓后四档自评；智能带权抽词 / 全库随机练习，默认10词，支持搜索范围、跳过、撤销、会话恢复与总结；FSRS在本地安排下次复习时间
- **全量导出**：生词本顶部「导出」可保存 JSON 或 CSV；完整保留释义、备注、次数、状态及所有原句/选词位置，不受搜索或自测影响，纯本地处理
- **极简模式**：支持 260×140 小窗，原文/译文切换、粘贴翻译与复制，退出恢复完整窗口
- **详情自动生成**：加入生词后自动调用大模型生成 音标 / 词性 / 中文释义 / 详细用法 / 3 条例句 / 近反义词 / 记忆提示
- **六套主题色**：青竹 / 靛蓝 / 鸢尾 / 琥珀 / 朱砂 / 石墨，自由搭配浅色 / 深色 / 跟随系统，实时生效并记忆偏好
- **折页 Logo**：标题栏自适应主题色，Windows 应用与托盘图标针对多尺寸优化；矢量源稿见 `build/logo.svg`，三个设计草案见 `build/logo-studies.svg`

## 技术栈

Electron 33 + electron-vite + React 18 + TypeScript + Tailwind CSS v3 + shadcn/ui + Zustand + sql.js（纯 WASM SQLite）+ ts-fsrs 5.4.2（纯 TypeScript 调度器）+ electron-builder（NSIS），无原生编译模块

## 使用提示

- 快速翻译：复制英文 →「粘贴并翻译」（Ctrl+Shift+V）；该操作替换整段原文
- 翻译：输入英文 → Ctrl+Enter 或点击「翻译」；翻译中可停止、修改原文或清空
- 右键粘贴：原文中替换选区或插入光标处；极简译文侧粘贴会换成新原文
- 加词：摘录区逐位置点词/拖选短语 → 检查带词序号的待加入条目 → 直接加入；同形词不会联动勾选，待加入标签可独立取消
- 词形：归一完成后才入库，失败保留选择可重试；“✓”仅表示当前原文的该位置已有摘录，旧来源若未记录位置不推断标记。词条展开「摘录来源」可查看并高亮当时选中的具体位置
- 查词：普通模式「查词」→ 输入单个英文单词 → Enter；无上下文的歧义词保留原词并说明，支持连字符/撇号，查询结果切换菜单后保留
- 收藏：查词结果点击「加入生词本」，已有词显示「已收录」，保留原备注与详情；普通摘词重复加入仍使次数 +1
- 语料推荐：在「查词 → 为你推荐」点「导入语料」，选择 TXT、Markdown、DOCX 或带文字层的 PDF 即可。本地按词频、词库和推荐反馈筛选英文词，空批次立即展示，有未消费词时保留当前顺序，刷新优先取语料词。单文件上限 16 MiB、200 万字符，PDF 至多 1500 页。扫描件需要已有文字层。
- 语料筛选模式：默认为「本地筛选」。选「AI 精筛」后直接导入，应用使用设置中的模型，仅发送候选 ID、单词拼写、变形和目标难度。每批最多 40 词，按模型用量计费。任务完成后一次性入池；可以暂停，退出或失败后点「继续精筛」从已保存的批次接着处理。单个词的答复无效会跳过，其他词继续处理；复筛已有候选时，跳过的词保留原样。点击推荐词才生成词条。模式选择会保存在本机。
- 候选词管理：在查词页点「预览语料词」，可逐项勾选、跨页全选和批量删除。点击「AI 精筛全部」可直接复筛现有候选；勾选后按钮只处理所选词。每批最多 40 词，完成后更新列表。删除立即保存，当前批次内的其余词按原顺序补位。
- 模型推荐：查词页空态自动参考词库生成，首次可能需要分析；空词库先选择 A1–C2 起始难度。等级是词汇难度估计，不是能力测评
- 推荐队列：一批10个候选全部保存在本地，每次显示前3个。查词成功、收藏或标记后移出对应词，由同批下一个补位；失败/取消查词不消耗。页面显示本批剩余数量；不足3个时展示实际余量，耗尽后等待手动刷新，不自动付费生成。模型返回不足10个有效词时保留有效结果，也不自动追加请求
- 推荐反馈：「已认识」长期排除该词及其列出的变体；「不感兴趣」冷却90天并降低相关主题优先级。可在「已标记」中撤销，但不会将已消费词插回本批。展示词冷却7天，成功查询过的词冷却30天
- 推荐更新：手动刷新优先取语料池，池中无适配候选时按原条件请求模型；切换页面、缓存过期、模型变化和重启均保留未消费队列与顺序。难度反馈调整下次推荐的目标；刷新失败或取消保留队列。批次、消费进度与反馈随数据库落盘，旧版候选缓存会本地接入至多10个
- 推荐使用当前模型（主进程请求），最多抽取60个代表词，必要时按20词分批分析，缓存只对新增/变化的词重新分析；不发送个人备注或整份词条详情
- 配色：设置 → 外观 → 主题色 / 明暗模式；标题栏日月按钮切换深浅色，在设置中可恢复跟随系统
- 复习：生词本 → 开始自测 → 选择抽词方式、词数和范围 → 开始本轮 → 回忆 → 揭晓 → 四档自评；空格揭晓，数字1–4评分
- 词库视图：搜索框下切换列表 / 词云 / 分组，共用当前搜索与学习状态筛选；视图、排序和词云指标会记住。刷新按钮可更新记忆快照，悬停查看快照时间
- 导出：生词本 → 导出 → 选择 JSON / CSV → 保存文件；在系统窗口选择位置，完成后显示实际数量和可复制的文件路径。所有状态的已保存词条均导出，默认按字母排序
- Base URL 需要带 `/v1`（如 `https://api.openai.com/v1`），无需以斜杠结尾
- 生词详情生成采用串行队列（每词间隔 300ms），大量加词时请耐心等待

开发验证可在 PowerShell 中设置 `$env:MY_TRANSLATE_USER_DATA="$env:TEMP\my-translate-test"` 后运行 `pnpm dev`，使用独立数据目录；安装版忽略该变量。清除变量后恢复普通开发目录。不要把真实 API Key 或用户数据放进仓库。

## 自测与记忆调度

### 怎么练

- 默认智能随机、每轮10个词；可选5/10/20/50个，以及全部词库或当前搜索结果。仅已完成且有简释的词参与，不足时按实际数量出题。
- 先回忆，再揭晓。`1 忘了`（没想起/想错）、`2 费力想起`（揭晓前确实想出）、`3 记得`（正常独立回忆）、`4 很熟`（立即且确定）。看到答案后才觉得熟悉，应选“忘了”。
- 评分按钮下显示预计间隔；窄窗中揭晓、评分、跳过和撤销固定在底部。原句、备注和完整用法可在揭晓后展开。
- 「退出自测」回列表并保留进度；切换菜单可直接继续，重启后从「开始自测 → 继续上次自测」恢复。「结束本轮」主动结束，未回答题目不会被记为遗忘。
- 可撤销上一题，恢复该词的原记忆状态与队列。跳过不评分。总结单独显示首次自评、跳过、额外加练和仍需巩固词，避免加练成功抬高首次表现。

### 怎么抽

- **智能随机**：约80%到期词＋20%未测词，池不足时互补；到期数达到本轮数量的3倍时暂不加新词。未到期词不会被用来凑数。
- 到期名额约20%留给最早到期词；其余依据估计遗忘风险、逾期程度和最近一次是否遗忘赋予有上限的权重，按 `-ln(U)/weight` 带权不放回抽样。未测池保留最老未测词，其余仅温和参考近期收录与摘录次数。
- 一轮的初始词条不重复，队列在重渲染/重启时保持稳定；只有开始新一轮才重新抽样。全库随机模式均匀抽样，允许提前练习，按实际时间记录评分。
- 选择“忘了”后，至少隔3道其他题且满足短期复习时间才进入本轮加练，同词最多额外2次。没有合适下一题时完成本轮，复习时间保留到稍后，不强迫等待或立即重复。

### 怎么记

- 使用锁定版本 `ts-fsrs@5.4.2` 的FSRS-6调度器，官方默认记忆参数、目标保持率0.9、短期步骤1分钟/10分钟。90%是调度参数，并非实际效果保证；抽样权重是可解释的初始启发式规则。
- 记忆状态、评分日志和会话独立保存在本地数据库，复习次数不改变原词条的摘录次数、备注和更新时间。每题事务写入，按项目数据库防抖策略落盘，正常退出时强制保存。
- 自测与调度无需联网。单词释义使用已生成资料，长期记忆表现仍取决于实际复习和自评质量。

## 熟悉度与词库可视化

- **长期熟悉度**参考FSRS稳定性、学习/重学状态及有效评分日志；**当前遗忘风险**为 `1 - FSRS当前回忆概率`。刚看过答案时可能显示“待巩固 · 风险低”，分别表示长期基础薄弱与此刻短暂能回忆。
- **未自测**：尚无记忆卡片；**待巩固**：最近选“忘了”或正在重学；**学习中**：仍在学习阶段，或跨日成功回忆依据不足；**逐渐稳定**：已进入复习阶段并有跨日依据；**较稳固**：在上述基础上稳定性达到30天。
- 跨日依据要求至少两次成功自评相隔24小时以上；跳过与撤销记录不计入。一日内反复点“很熟”仍属初步估计。30天是展示分档阈值，等级与概率都是记忆模型的估计，不是能力认证。
- 熟悉度排序按阶段、稳定性排列，未自测单独置后；遗忘风险排序按当前概率排列，无估计的词在末尾。风险低/中/高分别对应估计遗忘概率≤10%、≤25%、>25%；到期状态独立显示。
- 列表可展开「记忆概况」；词云和分组点击单词打开同一详情弹窗，支持原句、完整用法、备注保存和删除。备注修改导致词条退出当前搜索结果时，已打开详情仍可继续使用。
- 词云以完整单词/短语布局，字号范围有界并适配窗口；未自测在熟悉度相关指标下使用中性字号。每次默认尝试150词，可增加容量至450；放不下的词在补充区域分页显示，完整词条可搜索和访问。
- 相同数据/尺寸的词云布局稳定，切换主题只改变配色。进入词库、退出自测、窗口重新激活及手动刷新时计算统一时间快照；自测评分/撤销完成后同步更新可见词库，后台隐藏列表不逐题重算。
- 展示使用独立的学习摘要查询接口，本地读取既有FSRS数据与评分日志，无需模型请求。数据库结构仍为v5。

## 词库导出格式与分析

文件名默认包含本地导出时间，如 `my-translate-vocabulary-20261009-153000.json`。保存位置确认后读取当前完整词库快照，包含 `ready` / `pending` / `failed` 状态；生成中条目以后完成时，可再次导出获取最新内容。

### JSON（推荐程序分析）

- UTF-8，`schemaVersion: 1`；顶层包括 `application`、`exportedAt`（UTC ISO 日期）、`entryCount` 和 `entries`。
- 每条包含 `id / word / phonetic / pos / brief / detail / note / status / failReason / count / contextSentence / createdAt / updatedAt / sources`。
- `detail` 是完整 Markdown；`createdAt` / `updatedAt` 保留 Unix 毫秒时间戳。
- `sources` 是完整摘录数组，含 `original / word / explanation / context`，有位置的来源另含 `selection.start/end`。旧来源没有位置时不推断补全。
- 位置是 UTF-16 code unit 范围 `[start,end)`，与 JavaScript `String.slice` 一致；含 emoji 等字符时，Python 字符序号不能直接代替该单位。

```python
import json

with open("vocabulary.json", encoding="utf-8") as file:
    data = json.load(file)

entries = data["entries"]
words = [entry["word"] for entry in entries]
ready_entries = [entry for entry in entries if entry["status"] == "ready"]
```

### CSV（表格与 pandas）

- UTF-8 BOM，逗号分隔，标准双引号转义，CRLF 行分隔，一行一个词条；字段内换行、中文与长内容完整保留。
- 列：`id, word, phonetic, pos, brief, detail, note, status, fail_reason, count, context_sentence, created_at_ms, updated_at_ms, created_at, updated_at, original_forms, source_count, sources_json, csv_escaped_columns`。
- `created_at / updated_at` 为 UTC ISO 日期，`*_ms` 为原始毫秒时间戳。
- `original_forms` 是去重原词形的 JSON 数组；`source_count` 为来源数量；`sources_json` 保留完整来源数组。
- 公式样式的文本（例如备注以 `=` 开头）加单引号作为表格文本处理；`csv_escaped_columns` 明确列出被添加前缀的列名，程序可只对这些列移除首字符恢复原文。JSON 中的原文不作此转换。

```python
import csv
import json

with open("vocabulary.csv", encoding="utf-8-sig", newline="") as file:
    rows = list(csv.DictReader(file))

for row in rows:
    for column in json.loads(row["csv_escaped_columns"]):
        row[column] = row[column][1:]
    row["sources"] = json.loads(row["sources_json"])
    row["count"] = int(row["count"])
```
